# داده‌های دوره

همهٔ داده‌های این پوشه برای دورهٔ مهندسی LLM ساخته شده‌اند. فروشگاه **نوین‌کالا**، سیاست‌ها، شمارهٔ تماس، کالاها، قیمت‌ها و نظرات آن فرضی‌اند.

| فایل | محتوا | جلسه |
|---|---|---|
| `novinkala_docs/` | ۱۲ سند سیاست‌های فروشگاه (ارسال، بازگشت کالا، گارانتی، پرداخت و ...) به صورت Markdown | ۶ تا ۹، ۱۳ تا ۱۶ |
| `novinkala_handbook.docx` و `novinkala_handbook.pdf` | همان اسناد در قالب یک فایل Word و یک فایل PDF | ۷ |
| `novinkala_chunks.jsonl` | اسناد نرمال‌شده و تقسیم‌شده به ۴۲ تکه (خروجی جلسهٔ ۷) | ۸، ۹، ۱۳ تا ۱۶ |
| `rag_eval.jsonl` | ۳۰ پرسش با پاسخ مرجع، سند منبع و عبارت شاهد (Evidence) | ۵، ۷ تا ۹ |
| `products.csv` | ۲۴ کالا با قیمت، موجودی، رنگ و گارانتی | ۳، ۱۲ تا ۱۶ |
| `reviews.csv` | ۴۸ نظر کوتاه مشتری با برچسب positive، negative یا neutral | ۴ و ۵ |
| `orders_train.jsonl`، `orders_test.jsonl` و `orders_real.jsonl` | پیام‌های سفارش فارسی و سفارش ساختاریافتهٔ هر کدام، ساخته‌شده با [`order_data.py`](../order_data.py) | ۱۰ و ۱۱ |
